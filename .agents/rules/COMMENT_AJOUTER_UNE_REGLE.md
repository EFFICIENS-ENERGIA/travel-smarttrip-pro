# 📖 GUIDE RAPIDE : COMMENT AJOUTER UNE NOUVELLE RÈGLE (ESPACE SEB)

Bienvenue dans votre espace officiel de gestion des règles. Ce dossier a été spécialement configuré pour vous permettre d'ajouter, modifier ou enrichir les règles de développement de tous vos projets, à tout moment et en toute simplicité.

---

## 🚀 Étape 1 : Créer votre nouvelle règle

1. Ouvrez ce dossier : `Desktop\ANTIGRAVITY\projects\REGLES\`
2. Faites un simple copier/coller du fichier modèle : [`MODELE_NOUVELLE_REGLE.md`](./MODELE_NOUVELLE_REGLE.md)
3. Renommez votre copie en respectant la numérotation séquentielle, par exemple :
   - `08_VOTRE_NOUVELLE_REGLE.md`
   - `09_AUTRE_REGLE_METIER.md`
4. Ouvrez le fichier avec le Bloc-notes ou votre éditeur préféré et écrivez vos consignes.

---

## 🤖 Étape 2 : Prise en compte immédiate par l'Équipe Multi-Agents

Dès que vous ajoutez ou modifiez un fichier dans ce dossier :
- **CE (Chef d'Équipe)** et l'ensemble des agents (**AUD**, **DEV**, **UIX**, **OPS**, **DOC**) découvrent automatiquement votre nouvelle règle au démarrage de chaque interaction.
- La règle acquiert immédiatement le statut d'**obligation intangible (valeur contractuelle absolue)**.
- **AUD (Auditeur Senior)** intègre automatiquement votre règle dans son protocole de banc d'essai sous Edge Headless.

---

## ⚡ Étape 3 (Facultative) : Synchronisation 1-Clic

Si vous souhaitez propager instantanément votre nouvelle règle sur tous les dossiers système machine en un seul clic :
- Faites un clic-droit sur le fichier [`synchroniser_regles.ps1`](./synchroniser_regles.ps1) puis choisissez **« Exécuter avec PowerShell »**.
- Le script copie automatiquement votre règle vers :
  1. Le projet courant (`$HOMEagy2-projectsmy-first-project`)
  2. Le dossier système Antigravity (`.agents/rules/`)
  3. La configuration globale machine (`%USERPROFILE%\.gemini\config\rules\`)
